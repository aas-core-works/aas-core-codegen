The type annotation List[Mapping[str, int]] of the argument 'counts' of the verification function 'clear_all' is contradictory: the argument is mutable, as declared by List, while Mapping[str, int] declares a read-only dictionary. The mutability of an argument is deep, so all the nested lists, sets and dictionaries of a mutable argument are mutable as well. Please declare it as List[Dict[str, int]], or as Sequence[Mapping[str, int]] if the function does not mutate the argument.
