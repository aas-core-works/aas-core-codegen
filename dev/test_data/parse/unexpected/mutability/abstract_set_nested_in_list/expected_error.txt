The type annotation List[AbstractSet[str]] of the argument 'texts' of the verification function 'clear_all' is contradictory: the argument is mutable, as declared by List, while AbstractSet[str] declares a read-only set. The mutability of an argument is deep, so all the nested lists and sets of a mutable argument are mutable as well. Please declare it as List[Set[str]], or as Sequence[AbstractSet[str]] if the function does not mutate the argument.
