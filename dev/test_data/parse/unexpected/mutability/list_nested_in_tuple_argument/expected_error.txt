The type annotation Tuple[List[str], int] of the argument 'pair' of the verification function 'first_filled' is contradictory: the argument is read-only, as a tuple is read-only, while List[str] declares a mutable list. The mutability of an argument is deep, so all the nested lists, sets and dictionaries of a read-only argument are read-only as well. Please declare it as Tuple[Sequence[str], int].
