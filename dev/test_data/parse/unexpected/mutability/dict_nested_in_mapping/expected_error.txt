The type annotation Mapping[str, Dict[str, int]] of the argument 'counts' of the verification function 'some_func' is contradictory: the argument is read-only, as declared by Mapping, while Dict[str, int] declares a mutable dictionary. The mutability of an argument is deep, so all the nested lists, sets and dictionaries of a read-only argument are read-only as well. Please declare it as Mapping[str, Mapping[str, int]], or as Dict[str, Dict[str, int]] if the function mutates the argument.
