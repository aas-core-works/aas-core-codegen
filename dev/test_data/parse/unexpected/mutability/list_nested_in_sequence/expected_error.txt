The type annotation Sequence[List[str]] of the argument 'texts' of the verification function 'all_filled' is contradictory: the argument is read-only, as declared by Sequence, while List[str] declares a mutable list. The mutability of an argument is deep, so all the nested lists, sets and dictionaries of a read-only argument are read-only as well. Please declare it as Sequence[Sequence[str]], or as List[List[str]] if the function mutates the argument.
