We support Optional only at the top of a type annotation, but the argument 'texts' of the method '__init__' of the class 'Something' has the type List[List[Optional[str]]], which nests Optional[str]. The items of the lists, the tuples and the sets can not be optional, and an optional can not be optional itself, since the nested optionals can not be de/serialized in JSON and XML on many targets.
