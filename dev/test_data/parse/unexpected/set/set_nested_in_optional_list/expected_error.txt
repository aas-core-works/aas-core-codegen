The type annotation Set[str] is not allowed in the argument 'texts' of the method '__init__' of the class 'Something'. We support the sets only in the arguments of the verification functions and of the methods and in the properties, at the top of the type annotation or directly under Optional, and in the constant sets. The return values and the nested type annotations can not be sets at the moment. Please contact the developers if you need this feature.
